# macOS 手动切换与回滚指南

> 已在假数据上完成切换和回滚演练，但**尚未实际切换生产服务**。请只在自行确认的停服窗口操作；实际切换须以已审、已提交且经验证的 W HEAD 完整 OID 为目标。

## 四步简版

1. 提前另开本机终端；自己暂停新请求、等在途完成、停旧服务并禁自启，冻结主仓和 W 的编辑及 Git 操作。
2. 在新终端手动运行下文切换命令，按实际环境回答提示，记录事务 ID。
3. 切换成功后，自己按已核验的启动上下文 `on` 新服务并验收。
4. 新版验收失败时，自己停新服务、禁自启并重新冻结编辑和 Git，再用该事务 ID 运行下文回滚命令。若切换脚本本身失败或中断，不要直接回滚或重试，按「失败或中断」保留现场处理。

脚本**不负责停服或启动**。回滚取回旧版本和切换前配置/sidecar/账本，新版期间变化可丢失；完整命令、输入和风险见下文。

## 已验证范围

- 真实 W 的新端口服务对接本机 mock，已测试 A2A、A2R、R2A 的 JSON 和 SSE；初始化提示由测试插桩提供，不是生产真实切换。
- 切换/回滚脚本的 fake Git/PTY 测试覆盖了配置和 sidecar 的 A→B→A，以及账本 100→103→100。
- **尚未实际对生产服务停服切换**；上述测试不等于生产验收。本工具只面向 macOS 当前默认配置布局，不是通用迁移工具，也不代表原生 Windows 已通过验收。

## 范围与风险

- 脚本不启停服务、不发送信号、不处理登录态。旧账本已经丢失或未落盘的统计，不在脚本恢复范围内；只能以最后可验证的磁盘账本为准，内存增量仍可能丢失。无法接受缺账时不要执行。
- 切换事务在改版本前私有保存业务配置、sidecar 和旧账本快照，并在事务记录中保存旧 commit OID；旧代码对象仍依赖共享 Git 仓库，**不是独立的代码库备份**。事务及备份可能含敏感信息，保存在脚本输出的私有位置，勿提交、公开或删除。
- 默认业务配置为主仓 `config/model_proxy_config.json`，sidecar 为同目录 `session_overrides.json`，旧账本为主仓 `.model_proxy_totals.json`。旧账本和配置必须存在；sidecar 可原本不存在。脚本仅支持可核验的当前用户 0600 单链接普通文件；软链、非 0600、身份不明对象等会保守拒绝，不能靠强制覆盖绕过。原本不存在的 sidecar 后来出现未知对象时，也会拒绝读取或删除。
- 回滚恢复旧 commit 和**切换前**的配置、sidecar、账本快照，不合并新版统计；新版运行期间的配置、路由和统计允许丢失。用户已明确接受丢失切新版本期间的数据。客户端登录态和 `appkey_file` 原文件不由脚本覆盖；无关文档、凭据、第三方文件、共享 Git 和嵌套 W 不应被删除，遇到无法安全处理的对象应停下核查。
- 回滚时，`.runtime/tmp` 和 `.runtime/backups` 即使非空，也可在验证正规目录、身份和同卷等条件后，**整个目录**迁到私有事务目录保留；不跟随目录链接，也不遍历或清空目录内容。若 `.runtime` 根目录有未知对象，或目录、路径身份等异常，脚本仍会拒绝并保全现场。
- 切换时先安全快进 Git 并验证新提交的忽略规则，再安装旧账本快照；中断时停服保留现场，不自动恢复。
- 锁只约束协作者，不能防止他人并发删除 ignore 哨兵或 Git 竞态；多文件事务并非全局原子操作。切换或回滚全程必须冻结主仓和 W 的编辑及 Git 操作，禁止其他人、自动任务操作；这是程序安全前提，不能据此声称绝对保证。

## 执行前准备

1. 确认切换脚本及 R2A 补丁**均已提交**，且目标是经过验证的完整 W HEAD；在此之前不要执行。目标必须不同于旧 HEAD，并包含旧 HEAD 和脚本要求的基准提交。脚本会核验主仓/W 的身份、分支和 Git 状态；拒绝时不要绕过。
2. 停服务可能断开当前对话，**提前另开本机交互终端**，准备保留命令、输出的事务 ID 和保全位置。必须由当前非 root macOS 用户在可用的交互终端操作，不能用非交互代答；需要 Python 3.10 或更高版本。
3. 据旧服务**实际历史启动方式**核验旧 cwd、HOME、监听地址/端口，以及 `MODEL_PROXY_CONFIG`、`MODEL_PROXY_PORT` 的原值；分别核验计划新启动的 cwd、HOME、监听和环境。不能把当前 shell 的 cwd 或 HOME 当作旧服务的证明，也不能凭端口变量单独推断实际监听。旧/新启动须使用相同的 `MODEL_PROXY_CONFIG` 原值，并解析到默认配置路径；凭据引用的解析结果也须一致。
4. 此机此前只读观察到某个旧进程的 cwd 为 `/Users/vincentwang/Documents/NoteVault`、HOME 为 `/Users/vincentwang`、`MODEL_PROXY_PORT` 为 `18889`，未发现 `MODEL_PROXY_CONFIG`；**未发现不等于未设置**。这些仅供排查，执行时须重新核验实际服务，不固定 PID，也不要据此替代启动历史证据。
5. 在冻结 Git 前设置变量，检查 `TARGET` 确实为上述已提交、已验收的完整 W HEAD。以下空值必须由操作者填入已核验的值；路径须为明确的绝对路径，不能含 `..`：

   ```bash
   W="/Users/vincentwang/Documents/NoteVault/tools/model_proxy/.claude/worktrees/qw/feat-windows-unified-cli"
   ROOT="/Users/vincentwang/Documents/NoteVault/tools/model_proxy"
   TARGET="$(git -C "$W" rev-parse --verify 'HEAD^{commit}')"
   PORT=''      # 旧实例实际监听端口
   OLD_CWD=''   # 旧服务实际启动 cwd
   NEW_CWD=''   # 计划新服务启动 cwd
   OLD_HOME=''  # 旧服务实际启动 HOME
   NEW_HOME=''  # 计划新服务启动 HOME
   ```

## 手动切换

1. 用户暂停新请求、等待在途请求完成，手动停稳旧服务及所有相关实例，并关闭所有自动拉起入口；冻结主仓和 W 的编辑与 Git 操作，直至事务结束。进程和端口扫描不能识别所有改名或自定义入口，扫描通过不代替人工核实。
2. 用户在预先准备好的交互终端执行：

   ```bash
   bash "$W/tools/macos_switch.sh" --root "$ROOT" --target "$TARGET" --port "$PORT" --old-cwd "$OLD_CWD" --new-cwd "$NEW_CWD" --old-home "$OLD_HOME" --new-home "$NEW_HOME" --manual-stopped --auto-start-disabled
   ```

   两个声明参数是操作者的声明，**不是脚本证明**。按提示分别填写旧/新共同的 `MODEL_PROXY_CONFIG` 原值、旧和计划新的 `MODEL_PROXY_PORT` 原值；只有对应启动环境经核验确实未设置时才填 `UNSET`，不确定就停止。核对预览的配置/sidecar 路径和新旧监听地址及端口，确认一致后按提示输入；同时明确接受可能缺账。不要把敏感输出公开。
3. 记录输出的**事务 ID** 和私有保全位置；事务成功后仍不会自动启动。用户自行检查结果、启动新版本并验收，再恢复请求和自动拉起。验收不通过时，按下节处理。

## 回滚

1. 用户先暂停新请求、等待在途完成，手动停稳新服务及所有相关实例，关闭全部自动拉起，重新冻结主仓和 W 的编辑及 Git 操作。使用**同一主仓、同一 W 和切换成功时记录的事务 ID**；核对旧 commit 与快照保全仍可用。
2. 在交互终端将 `TXN` 设为记录的事务 ID，再执行：

   ```bash
   TXN=''  # 填入切换成功输出的事务 ID
   bash "$W/tools/macos_rollback.sh" --root "$ROOT" --transaction "$TXN" --manual-stopped --auto-start-disabled
   ```

   回滚端口和启动上下文从事务记录读取；人工核对记录中的新版实际监听，以及新旧 cwd/HOME 的反向对应，按提示确认并接受可能缺账。脚本成功后用户自行核验旧 commit 和切换前配置、sidecar、账本，再启动旧服务并验收；脚本不启动服务。

## 失败或中断

保持停服、禁自动拉起、冻结编辑和 Git；保留事务、备份与现场。**不要 `git add`/`push`、硬重试、`reset --hard` 或 `git clean`，不要删除 `.runtime`、锁、未知文件或备份。** 账本可能未被 Git 忽略；输出的最后阶段可能滞后，不能当作完整状态证明。

若已有事务 ID，异常检查可在同样停服和冻结条件下运行下列命令；`--recover` 只检查/报告 `UNKNOWN`，不自动恢复或重放，也不是普通回滚：

```bash
bash "$W/tools/macos_rollback.sh" --root "$ROOT" --transaction "$TXN" --manual-stopped --auto-start-disabled --recover
```

人工保全并核对事务 manifest、Git HEAD/index、旧/新账本身份及摘要；身份或状态不能闭合时继续停服，先审查并另定恢复方案。若只有候选 ID 或尚无事务 ID，也不得假定事务已经成功创建或可以回滚。
